# Solicitud al cliente — Search Console, URLs antiguas y Google Business Profile

**Para:** Arenal Discovery  
**Asunto sugerido:** Accesos y exports para el rescate SEO de arenaldiscovery.com  
**Relacionado:** [propuesta-seo-geo-arenal-discovery.md](./propuesta-seo-geo-arenal-discovery.md) §7  

Sin estos insumos no se puede cerrar el mapa de redirecciones 301 ni afinar horas del paquete 2 (URLs `/trip/` y `/activities/`).

---

## Texto para enviar (copiar y pegar)

Hola,

Para armar el plan de redirects y el presupuesto fino de SEO necesitamos accesos y unos exports. No hay que cambiar nada en el sitio todavía.

### 1. Google Search Console

- Usuario con permiso de lectura en `arenaldiscovery.com` (y `www`, si está como propiedad aparte), **o**
- Exports CSV de los últimos 16 meses (si no, 3 meses):

  1. Rendimiento → **Páginas**: URL, clics, impresiones, CTR, posición  
  2. Indexación → **Páginas**: indexadas / detectadas / excluidas  
  3. Lista o filtro de URLs que contienen `/trip/` y `/activities/`  
  4. Rendimiento → **Consultas**: top 50  
  5. Si aparece en el panel: datos de AI Overviews / modo IA  

### 2. Google Business Profile (Maps)

- Confirmar si existe ficha de Arenal Discovery en Google Maps.  
- Si existe: acceso de administrador o captura de NAP (nombre, dirección, teléfono, horarios, categorías).  
- Si no existe: indicarlo; lo cotizamos como alta nueva.

### 3. Analytics

- ¿Hay Google Analytics 4? Si sí, acceso de lectura o el Measurement ID.

### 4. Confirmaciones rápidas

- Dirección pública exacta (en el sitio figura “Main Street, La Fortuna, 21007”).  
- Teléfono y WhatsApp oficiales.  
- Idiomas que quieren **indexar** (recomendamos inglés + español en fase 1).  
- Si recuerdan el equivalente de estas URLs viejas (hoy dan 404):

| URL indexada | ¿Sigue siendo un tour? | URL nueva (si la conocen) |
|---|---|---|
| https://arenaldiscovery.com/trip/catarata-la-fortuna/ | | |
| https://arenaldiscovery.com/trip/sky-trek-best-canopy-tour/ | | |
| https://arenaldiscovery.com/trip/tour-de-rafting/ | | |
| https://arenaldiscovery.com/activities/quadcycle/ | | |

El listado completo lo sacamos de Search Console; estas cuatro ya aparecen en Google.

Gracias.
